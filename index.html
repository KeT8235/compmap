사용방법 / 기능소개
아이콘
  • 아이콘을 드래그해서 맵 위에 놓습니다.
  • 복제된 아이콘은 더블클릭으로 삭제됩니다.
  • 원본 아이콘을 우클릭 → 커서 따라다님 → 맵에서 우클릭하면 빠르게 배치됩니다.
  • 빠른 배치 모드는 ESC 또는 맵 좌클릭으로 해제됩니다.
그리기(캔버스)
  • 색상/굵기 선택 후 연필(그리기) / 지우개(지우기)로 사용합니다.
  • 되돌리기: Ctrl+Z / 다시 실행: Ctrl+Y (또는 Ctrl+Shift+Z)
초기화/저장
  • 아이콘 지우기: 현재 맵 아이콘만 초기화
  • 낙서 지우기: 현재 맵 캔버스만 초기화
  • 전부 지우기: 현재 맵 아이콘+낙서 초기화
  • 브라우저 종료 시 자동 초기화: 체크 시 종료할 때 저장데이터 삭제
  • 모든 맵 데이터 삭제: 전체 맵 저장데이터 삭제
